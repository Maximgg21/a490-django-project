# a490-django-project
CSCE A490 WebDev

Working title and purpose
Card Codex is a web database for the game we are developing for another class.
Its purpose is to store card data, add/remove cards, and search existing cards by name or its features, such as rarity, cost, etc.

Intended users
At first, only I and my teammates were designing the game, and players later as a public card wiki.
It will be useful to look at the bigger picture while designing the game and also make it easier to find specific cards.

Core actions
Add/remove a card, edit a card, and browse and filter cards.

Stored data
Card data such as name, cost, type, rarity, description, art filename, and effects that you can filter by.
